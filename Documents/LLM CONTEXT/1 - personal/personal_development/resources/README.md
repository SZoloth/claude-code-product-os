## How to Use These Resources

### For Daily Reference
- Keep **conversation guides** handy for social situations
- Use **procrastination guides** when facing resistance to important tasks
- Reference **agency guides** when feeling stuck or low-energy

### For Systematic Development
- Work through guides sequentially rather than jumping around
- Practice techniques consistently before moving to new ones
- Integrate learnings with your Core Plans & Philosophy

### For Specific Challenges
- **Low agency/motivation**: Focus on agency guides and motivation resources
- **Social anxiety**: Start with social skills and conversation guides  
- **Procrastination**: Use the procrastination-specific guides
- **Strategic decisions**: Reference infinite games and long-term thinking

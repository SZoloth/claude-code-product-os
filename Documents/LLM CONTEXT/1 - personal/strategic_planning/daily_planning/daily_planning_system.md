# Daily Planning & Logging System (Things-Integrated)

## Overview
This system helps you plan productive days, track progress, and reflect on what actually happened using **Things as your single source of truth** for task execution. Your strategic planning documents remain the vision source, while Things drives daily execution.

## Integration Philosophy
- **Things = Execution Engine**: Daily tasks, deadlines, project management with priority filtering
- **Strategic Docs = Vision Source**: Long-term planning, goal setting, strategic frameworks
- **Daily Plans = Integration Bridge**: Combines Things data with strategic guidance for coordinated execution

## Daily Workflow
1. **Morning Planning** (7-12 minutes): Pull from Things, coordinate with agents, create schedule, body/edge check
2. **Execution**: Work from Things with daily plan as context, notice edge moments
3. **Evening Reflection** (7-8 minutes): Update Things status, reflect on progress, self-enquiry practice, adjust priorities

## Things Priority System
Your daily planning uses Things priority tags:
- **P1 (High Priority)**: Must happen today - time-sensitive tasks, critical deadlines
- **P2 (Medium Priority)**: Should happen today - important project work, development tasks
- **P3 (Quick Wins)**: Fill available time - small tasks, multitasking opportunities

- 6:30-7:00: Morning reflection & Things review

#### **Work Day Gaps (Variable)**
- Lunch breaks: P3 quick wins, personal calls

- Work from home days: Longer lunch for P2 tasks

#### **Evening Strategic Block (6:00-8:00 PM)**
- 6:00-7:00: P1 priority tasks (financial, job search)
- 7:00-8:00: P2 project work OR creative skill focus

- Strategic planning sessions
- Major project advancement
- Creative skill intensive sessions
- Marathon long runs

### Calendar Management Strategy

#### **Weekly Planning (Sunday 30 minutes)**
1. Review Things projects and upcoming deadlines
2. Block morning/evening time for P1 priorities
3. Schedule weekend strategic sessions
4. Plan creative skill focus for the week

#### **Daily Adjustments (5 minutes each morning)**
- Confirm today's blocks still work with schedule
- Move tasks between morning/evening based on energy
- Protect at least one strategic block per day

## Usage Guidelines

### Morning Planning with Things (7-12 minutes)
1. **Body & Edge Check** (2-3 minutes):
   - Notice physical tension or defensive arousal
   - Check for Recognition/Impact control patterns
   - Identify potential edge opportunities for the day
   - Set one specific openness intention

2. **Pull from Things** (2 minutes):
   - Check today's tasks (`mcp__things__get-today`)
   - Review upcoming priorities (`mcp__things__get-upcoming`) 
   - Assess project status (`mcp__things__get-projects`)

3. **Strategic Alignment** (3 minutes):
   - Ensure P1 tasks align with strategic priorities
   - Balance project work across life domains
   - Account for marathon training requirements
   - Consider strategic development opportunities

4. **Schedule Integration** (3 minutes):
   - Time-block P1 tasks in protected slots
   - Schedule P2 tasks in focused work periods
   - Fill gaps with P3 quick wins
   - Add edge awareness prompts for each time block

### Throughout the Day
- Execute tasks using Things as your reference
- Update Things task status in real-time
- Add new tasks to Things immediately
- **Notice edge moments**: When resistance, defensive arousal, or "should" pressure arises
- **Brief body checks**: Pause when tension increases during task execution
- Use daily plan for schedule and context

### Evening Reflection & Sync (7-8 minutes)
1. **Self-Enquiry Practice** (3-5 minutes):
   - Identify one edge moment from the day
   - Notice where body tension showed up
   - Generate one good question (avoid quick answers)
   - Consider what could be "outed" to someone trusted

2. **Update Things Status** (2 minutes):
   - Mark completed tasks as done
   - Update project progress
   - Add tomorrow's tasks
   - Adjust priorities based on learnings

3. **Integration & Tomorrow Preparation** (2 minutes):
   - Note how openness practices affected execution
   - Set specific openness intention for tomorrow
   - Review Things priorities for tomorrow
   - Identify potential edge opportunities ahead

## RO-DBT Integration Guidelines

### Getting Started (Week 1-2)
- Focus only on morning body checks and evening edge identification
- Keep self-enquiry practices to 3 minutes maximum
- Don't worry about finding perfect questions - practice noticing edge moments

### Building the Practice (Week 3-4)
- Add edge awareness during task execution
- Begin identifying Recognition/Impact patterns in daily choices
- Practice one "outing" conversation per week with trusted person

### Signs of Over-Indexing (Watch For)
- Self-enquiry sessions longer than 5 minutes
- Getting frustrated when you "can't find the edge"
- Trying to solve problems during self-enquiry (vs finding questions)
- Making RO-DBT practice another task to perfect
- Avoiding self-enquiry when it reveals uncomfortable truths

### Adaptive Adjustments
- If you miss practice: do self-enquiry about the perfectionism around missing it
- If resistance arises: that's prime edge territory for exploration
- If overwhelmed: reduce frequency but maintain quality of attention
- If nothing seems "edge-worthy": practice self-enquiry about the need to find something

# Journal System

This directory contains a minimal journaling system for personal reflection and daily logging.

## Structure

- **entries/**: Daily journal entries organized by year and month
- **templates/**: Entry templates for different types of journaling
- **index.md**: Master index with quick navigation and search

## File Naming Convention

Journal entries follow the format: `YYYY-MM-DD.md`

Example: `2025-07-27.md`

## Usage

Use the journal management sub-agent to:
- Create new entries
- Search past entries
- Maintain consistent formatting
- Track themes and patterns over time

# CLAUDE.md - Journal

## Folder Purpose

This folder contains personal reflection and daily logging systems designed to support self-awareness, growth tracking, and life documentation through structured journaling practices.

## Key Guidelines

- **Personal Reflection**: Support deep self-reflection and personal growth through writing
- **Privacy Conscious**: Handle personal thoughts and experiences with appropriate care and confidentiality
- **Growth-Oriented**: Focus on learning, development, and positive forward movement
- **Consistent Practice**: Maintain regular journaling habits and documentation systems

## Content Organization

### Core Structure
- **index.md**: Main journal navigation and organization system
- **entries/**: Directory containing individual journal entries by date
  - **2025-08-01.md**, **2025-08-05.md**: Specific daily entries
  - **2025/**: Year-based organization for entries

### Templates and Systems
- **templates/**: Structured frameworks for different types of reflection
  - **daily-reflection.md**: Template for end-of-day reflection
  - **quick-log.md**: Template for brief daily logging

## Working with this Content

When working with files in this folder:

1. **Support Reflection**: Help structure thoughts and insights for deeper self-awareness
2. **Maintain Privacy**: Treat personal reflections with appropriate confidentiality
3. **Encourage Growth**: Focus on learning opportunities and positive development
4. **Consistent Structure**: Maintain organized systems for easy review and reference

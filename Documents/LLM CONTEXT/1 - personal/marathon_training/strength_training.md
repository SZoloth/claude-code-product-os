### **Phase 1: Foundation Building (Sep 5-25) - Weeks 1-3**

#### **Upper Body Strength (Wed/Sat) - 35-40 minutes**

**Equipment needed:** Dumbbells, resistance bands, pull-up bar/TRX

**Workout A (Wednesdays):**

1. **Push-ups or DB Chest Press** - 3 sets x 8-12 reps
2. **Bent-over DB Rows** - 3 sets x 8-12 reps 
3. **Overhead Press (DB/Pike Push-ups)** - 3 sets x 8-10 reps
4. **Lat Pulldowns/Pull-ups** - 3 sets x 5-10 reps
5. **Pallof Press (bands/cable)** - 3 sets x 10-12 each side
6. **Plank** - 3 sets x 30-60 seconds

**Workout B (Saturdays):**

1. **Incline Push-ups/DB Press** - 3 sets x 10-12 reps
2. **Single-arm DB Rows** - 3 sets x 8-10 each arm
3. **Pike Push-ups/DB Shoulder Press** - 3 sets x 8-10 reps
4. **Band Pull-aparts** - 3 sets x 15-20 reps
5. **Russian Twists** - 3 sets x 20-30 total
6. **Side Plank** - 2 sets x 20-30s each side

#### **Lower Body Strength (Tuesdays Only) - 25-30 minutes**

**CRITICAL:** Only on easy run days, minimum 4 hours after running

**Tuesday Lower Body Workout:**

1. **Bodyweight/Goblet Squats** - 3 sets x 10-15 reps
2. **Single-leg Glute Bridges** - 3 sets x 8-10 each leg
3. **Reverse Lunges** - 3 sets x 8-10 each leg 
4. **Single-leg Calf Raises** - 3 sets x 12-15 each leg
5. **Clamshells (band)** - 2 sets x 12-15 each side
6. **Wall Sit** - 2 sets x 30-45 seconds

#### **Daily Core/Stability (Post-run) - 5-10 minutes**

**Injury Prevention Focus:**

1. **Hip flexor stretch** - 30s each leg
2. **IT band stretch** - 30s each leg 
3. **Calf stretch** - 30s each leg
4. **Dead bug** - 10 each side
5. **Bird dog** - 8-10 each side
6. **Glute bridges** - 15-20 reps

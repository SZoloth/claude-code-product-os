# Daily Progress Logs

This directory contains daily progress summaries generated automatically to track knowledge work and insights.

## File Naming Convention
- `YYYY-MM-DD.md` - Daily progress entries

## Automation
- Run `npm run daily-progress` to generate today's progress file
- Files track modified documents, insights, decisions, and next steps
- Use `npm run catch-up` to get a summary of recent activity

## Manual Updates
After running the script, manually update the generated file with:
- Key insights from your work
- Important decisions made
- Blockers or questions that arose
- Focus areas for tomorrow

## Integration with Catch-Up System
These files are used by the catch-up script to provide quick context when resuming work after breaks.

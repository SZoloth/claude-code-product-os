# CLAUDE.md - Project Ideas

## Folder Purpose

This folder serves as an ideation space for potential projects, initiatives, and creative endeavors across personal and professional domains.

## Key Guidelines

- **Creative Exploration**: Encourage broad thinking and creative project concepts
- **Feasibility Balance**: Consider both ambitious and practical project ideas
- **Cross-Domain Thinking**: Explore projects that span multiple interests and skills
- **Implementation Readiness**: Help evaluate and prepare promising ideas for action

## Content Organization

Currently minimal - primarily contains README.md for project ideation framework. This folder is designed to grow organically as new project concepts emerge.

## Working with this Content

When working with files in this folder:

1. **Capture Ideas**: Document project concepts as they emerge without immediate judgment
2. **Develop Concepts**: Help flesh out promising ideas with more detail and structure
3. **Evaluate Feasibility**: Assess projects for practicality, resources, and timeline requirements
4. **Cross-Reference**: Connect project ideas to existing skills, goals, and resources

## Agent Recommendations

- Use **strategic-life-planner agent** for evaluating projects against long-term goals
- Use **learning-acceleration-coach agent** for skill-building project ideas  
- Use **personal-profile-manager agent** when projects relate to professional development
- Connect with **strategic_planning** folder for project integration into larger plans
- Use **productivity-optimization-specialist agent** for project management and execution planning

## Project Development Framework

When developing project ideas:

1. **Initial Capture**: Document the core concept and inspiration
2. **Scope Definition**: Define project boundaries and objectives
3. **Resource Assessment**: Evaluate required time, skills, and materials
4. **Goal Alignment**: Connect to broader personal and professional objectives
5. **Implementation Planning**: Break down into actionable steps and timelines

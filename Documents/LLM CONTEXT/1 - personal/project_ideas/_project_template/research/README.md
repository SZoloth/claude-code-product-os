# Research Folder

Store background information, sources, and reference materials here.

## File Naming Convention
- `source_[source-name]_[date].md` - External sources and references
- `existing_notes_[topic].md` - Relevant notes mined from vault
- `context_[area].md` - Background context from specific domains

## Content Guidelines
- Include source links and attribution
- Keep abstracts concise (1-2 lines)
- Tag connections to other vault areas

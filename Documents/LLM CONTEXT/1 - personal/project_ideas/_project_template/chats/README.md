# Chats Folder

Store conversation transcripts and external chat imports here.

## File Naming Convention
- `[date]_[platform]_[topic].md` - Chat transcripts
- `[date]_voice_[context].md` - Voice conversation transcripts
- `[date]_session_notes.md` - Claude Code thinking sessions

## Content Guidelines
- Include full transcripts with timestamps when possible
- Note the source platform (Claude, ChatGPT, Grok, etc.)
- Add brief context summary at top of each file

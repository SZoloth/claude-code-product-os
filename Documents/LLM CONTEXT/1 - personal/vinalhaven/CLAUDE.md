## Repository Overview

This repository contains markdown-based property management documentation for a property on Vinalhaven island. The repository is organized as a set of markdown files tracking different aspects of property management and maintenance.
This is not a coding project and you are not a coding assistant, instead you are an expert general purpose agent.

## Repository Structure

### Main Files
- **vinalhaven_projects.md**: Consolidated project tracking for building, trail, landscaping, and seasonal maintenance tasks
- **vinalhaven_connections.md**: Personal CRM for tracking island contacts, services, and relationships
- **vinalhaven_meal_planning.md**: Weekly meal planning, grocery lists, and kitchen inventory

### Project-Specific Files
- **projects/**: Directory containing detailed plans for specific projects
  - **projects/dock_ladder_installation.md**: Example project plan with steps, materials, and progress tracking

## Primary File Format

All files follow a consistent markdown format using tables to track items with properties like:
- Task/Item name
- Location
- Priority
- Status (typically "Backlog")
- Owner (typically "Sam")
- Notes
- Other relevant fields

## Common Tasks and Usage Patterns

### Adding New Tasks/Items
When adding new tasks or items to any tracker file:
1. Maintain consistent table formatting
2. Include all required columns (item, location, priority, status, etc.)
3. Set new items to "Backlog" status by default
4. Assign "Sam" as the default owner

### Creating Project-Specific Files
For significant projects requiring detailed planning:
1. Create a new markdown file in the projects/ directory
2. Use the standard project template with sections for:
   - Project Overview (goal, priority, timeline)
   - Requirements
   - Materials Needed
   - Installation/Execution Steps
   - Progress Log
   - Resources

### Updating Task Status
Task status can be updated from "Backlog" to:
- "In Progress" 
- "Completed"
- "On Hold"

### Priority Levels
Tasks can be categorized with priorities:
- High
- Medium
- Low

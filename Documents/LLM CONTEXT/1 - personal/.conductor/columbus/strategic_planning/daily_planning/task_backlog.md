## Task Management Guidelines

### Priority Definitions
- **HIGH PRIORITY**: Time-sensitive tasks with specific deadlines or significant consequences if delayed
- **MEDIUM PRIORITY**: Important tasks that should be completed soon but have some flexibility
- **LOW PRIORITY**: Tasks that can be done when time allows

### Status Tracking
- [ ] = Not started
- [~] = In progress  
- [x] = Completed
- [!] = Blocked/needs attention

### Weekly Review Process
1. Review all tasks every Sunday
2. Update priorities based on changing circumstances
3. Move completed tasks to "Completed Tasks" section
4. Add new tasks as they arise
5. Archive old completed tasks monthly

# Daily Planning

This directory contains daily planning systems, archived plans, and task management tools that translate strategic objectives into executable daily actions.

## Contents

### Current Planning
- **daily_plan_2025-08-03.md** - Current active daily plan with priorities and scheduled activities
- **daily_planning_system.md** - Framework and methodology for effective daily planning

### Task Management
- **task_backlog.md** - Repository of tasks and projects awaiting scheduling and prioritization
- **things_task_archive.md** - Archive of completed tasks and project outcomes for reference

### Historical Reference
- **past_day_plans/** - Archive of previous daily plans for pattern analysis and learning

## Daily Planning Philosophy

### Strategic Connection
- **Top-down alignment**: Daily actions connect directly to 30/60/90 day priorities
- **Bottom-up feedback**: Daily experience informs strategic planning adjustments
- **Energy optimization**: Schedule considers natural energy patterns and capacity

### Systematic Approach
- **Consistent framework**: Standardized planning format enables pattern recognition and improvement
- **Flexible execution**: Plans adapt to changing circumstances while maintaining priority focus
- **Learning integration**: Regular review of planning effectiveness drives system refinement

## How to Use This System

### Daily Planning Process
1. **Review strategic priorities** from Core Planning objectives
2. **Assess capacity** based on energy, commitments, and constraints
3. **Select focus areas** that advance key objectives
4. **Schedule specific actions** with realistic time allocation
5. **Plan for contingencies** and unexpected demands

### Weekly Review Cycle
- **Pattern analysis**: Review past_day_plans for effectiveness patterns
- **System refinement**: Adjust daily_planning_system.md based on learning
- **Strategic alignment**: Ensure daily actions support broader objectives
- **Capacity calibration**: Improve estimation of time and energy requirements

### Monthly Integration
- **Archive completed plans** to past_day_plans directory
- **Update task backlog** with new priorities and completed items
- **System documentation**: Capture lessons learned in daily_planning_system.md

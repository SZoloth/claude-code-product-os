# Core Planning

This directory contains foundational strategic planning documents that guide long-term vision, medium-term action planning, and systematic strategic analysis.

## Contents

### Long-term Vision
- **life_vision_2025-2030.md** - 5-year strategic vision encompassing career, relationships, health, and personal development goals

### Action Planning
- **30_60_90_day_action_plans.md** - Systematic approach to breaking down long-term vision into executable short-term actions

### Strategic Analysis
- **strategic_analysis_july_2025.md** - Comprehensive analysis of current situation, opportunities, and strategic options

## Planning Philosophy

### Systems Thinking
- **Integration**: All planning elements connect and reinforce each other
- **Flexibility**: Plans adapt to changing circumstances while maintaining strategic direction
- **Measurability**: Goals include specific metrics and milestones for tracking progress

### Time Horizon Balance
- **Long-term vision** (5 years): Provides direction and meaning for shorter-term decisions
- **Medium-term planning** (90 days): Bridges vision and daily action with concrete objectives
- **Short-term execution** (30 days): Immediate actions that advance medium-term goals

## How to Use These Documents

### Strategic Planning Cycle
1. **Annual Vision Review**: Update life_vision_2025-2030.md based on learning and changed circumstances
2. **Quarterly Action Planning**: Refresh 30_60_90_day_action_plans.md with next quarter's priorities
3. **Monthly Strategic Analysis**: Update strategic_analysis documents with current situation assessment

### Decision-Making Framework
- **Vision Alignment**: Evaluate opportunities and decisions against long-term vision
- **Action Priority**: Use 30/60/90 framework to prioritize competing demands
- **Strategic Assessment**: Apply analysis frameworks to complex decisions and trade-offs

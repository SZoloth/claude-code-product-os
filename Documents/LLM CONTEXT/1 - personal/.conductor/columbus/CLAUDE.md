- **Folders**: Consistent `snake_case` naming (e.g., `job_search`, `personal_development`)

- **Dates**: `YYYY-MM-DD` format throughout
- **Job Applications**: Zero-padded numbering with kebab-case (e.g., `01-canva`, `02-figma`)

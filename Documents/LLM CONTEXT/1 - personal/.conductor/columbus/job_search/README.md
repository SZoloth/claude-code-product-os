# Job Search

This directory contains comprehensive job search strategy, application materials, and company research organized for systematic career advancement and opportunity pursuit.

## Directory Structure

### Applications/
Company-specific application materials, research, and tracking for active job opportunities including Atlassian, Casa, Schneider Electric, and others.

### General Context/
Foundational job search strategy, templates, and reference materials that apply across all applications.

### my-experience/
Case stories, project summaries, and documentation of professional achievements that support application materials.

## Core Components

### Strategic Framework
- **Job Search Strategy Playbook.md** - Master strategy for systematic job search approach
- **Case-Story-Template.md** - Framework for developing compelling professional narratives

### Application Materials
- Customized resumes and cover letters for specific roles
- Company-specific research and intelligence reports

### Experience Documentation
- **Case_Stories_Repository.md** - Comprehensive collection of professional achievements

## Job Search Philosophy

### Strategic Approach
- **Quality over quantity**: Deep research and customization for each application
- **Relationship-first**: Prioritize connections and referrals over cold applications
- **Value demonstration**: Lead with concrete examples of impact and problem-solving

### Professional Positioning
- **Product leadership expertise**: Emphasizing strategic thinking and execution
- **Cross-functional collaboration**: Highlighting ability to work across teams and disciplines
- **Measurable impact**: Quantifying achievements and business outcomes

## How to Use This System

### For New Opportunities
1. **Research** using company_discovery_framework.md
2. **Create application folder** in Applications/ directory
3. **Develop case stories** relevant to the role using Case-Story-Template.md
4. **Customize materials** based on research and role requirements

### Ongoing Management
- **Track applications** using company-specific dashboards
- **Update case stories** with new achievements and projects
- **Refine strategy** based on feedback and market response

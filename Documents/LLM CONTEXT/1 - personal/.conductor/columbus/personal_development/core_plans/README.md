## Key Principles

These documents are built around the Security-Agency-Connection flywheel:
- **Security** (earned self-respect) enables taking action despite fear of rejection
- **Agency** leads to solving problems and creating value for others
- **Value creation** builds stronger relationships and trust
- **Stronger relationships** provide positive feedback that reinforces security
